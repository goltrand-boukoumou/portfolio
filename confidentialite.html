Politique de confidentialité

Dernière mise à jour : 23 octobre 2026.

Cette page décrit les traitements liés à la consultation du portfolio de Goltrand Boukoumou.

Mesure d’audience et cookies

Le code du site n’intègre actuellement ni outil de mesure d’audience, ni formulaire, ni cookie publicitaire. Les liens de contact ouvrent votre application de messagerie ; aucun message n’est envoyé à ce site.

Ressources externes

Le site charge des polices depuis Google Fonts. Lors du chargement de ces polices, votre navigateur contacte les serveurs de Google, qui peuvent recevoir des données techniques telles que votre adresse IP. Consultez les informations de confidentialité de Google. Le chargement de ces polices peut être bloqué par votre navigateur.

Hébergement

Le site est publié sur GitHub Pages. L’hébergeur peut traiter des données techniques nécessaires à la fourniture et à la sécurité du service. Pour en savoir plus, consultez la déclaration de confidentialité de GitHub.
